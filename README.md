# ReminderAI
If you wish to have an assistant by yourself to remind yourself important things throughout your journey, check this out!

You can tell your assistant important memos and it will remember it for you. Later if you forgot what you need to do you can just ask your assistant!

## Development
If you do not have `docker compose` installed, run `brew install docker compose`.

```
docker compose up
fastapi dev ./main.py
```
